# Source contract

## Current codebase truth

Primary navigation:

- `docs/codebase/README.md`
- `docs/codebase/.documentation-state.json`

Generated by `/document-vortex`.

The documentation is a snapshot at its `documentedCommit`. If current implementation changed,
verify code and refresh the affected documentation.

## Protocol/client truth

Primary:

- `docs/habbo-specs/`
- official target client `WIN63-202607011411-782849652`
- official captures when present

Query through `habbo-spec` / `Vortex.Specs.Cli`.

## Completeness denominator

Primary packet surface:

- official client;
- `EvidenceAuthority.ClientCode`;
- `TargetsSameRevision == true`;
- incoming;
- header resolved.

No Vortex-derived collection is allowed to define what the client is capable of requesting.

## Historical/reference sources

Reference emulators, audits and old docs may help locate evidence but cannot override:
current code for implementation facts or official-client/capture evidence for protocol facts.
