# Furniture logic

Generated by `habbo-spec completeness --write`. Never hand-edited: everything here is
reproduced from the target client and the current code on the next run.

A **third** denominator, and the one with the widest blast radius per gap. A missing
packet costs one interaction. A logic name nothing binds costs **every definition
carrying it**, silently — the furni resolves to its family default, places, sits
there and does nothing. No error, nothing a player can report but "it doesn't work".

Denominator: `Vortex.Database/Seeds/furni_logic_bindings.sql`, the committed asset-derived binding pass.
Definitions that already carried a registered Vortex logic are absent from it by
design — those were never at risk.
